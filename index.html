Module 1 reads conditions; Module 2 reads events. A condition holds whether or not anyone came into opposition. An event requires that something happened. Every case carries values on both, so a case can be an Enactment and still show a full set of instability conditions.

Module 3 · Downstream

Once an order exists, how does it reach actors and how are consequences distributed? This module works differently from the two axes above. It describes what happens to an order once it exists, whatever produced it.

Where to start
  • Unsure what the rule covers, or watching that shift → Module 1
  • Tracing how the rule reached its current shape → Module 2
  • Rule is settled; asking who it reached and how → Module 3

These are entry points, not a choice between three. Most cases carry values in all three modules, so this only decides where to begin reading.

Method

All three modules work the same way: they trace an order through the record it left. Rules, gazettes, filings, consultation records, corporate statements, reporting, whatever carries the thing being followed. What a case can say is limited by what was written down about it, and cases differ in how much that is.
