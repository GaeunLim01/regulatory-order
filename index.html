Case library

Real disputes, tagged against all three modules at once.

Super Micro, Anthropic v. DoW, Fable 5 →

Module 1 reads conditions; Module 2 reads events. A condition holds whether or not anyone came into opposition. An event requires that something happened. Module 3 works differently again: it does not classify a case, it describes what happens to an order once it exists, whatever produced it. The case library applies all three to documented disputes.

Method

All three modules work the same way: they trace an order through the record it left. Rules, gazettes, filings, consultation records, corporate statements, reporting, whatever carries the thing being followed. What a case can say is limited by what was written down about it, and cases differ in how much that is.
