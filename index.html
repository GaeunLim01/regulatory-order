Methodology

How does regulatory order form, and how does it reach the actors standing under it?

  • A Classification
  • B Formation
  • C Manifestation
  • D Distribution
  • E Re-formation

Layer A reads conditions; Layer B reads events. A condition holds whether or not anyone came into opposition. An event requires that something happened. Layer C is downstream of both. Layer D and Layer E apply once an order exists, regardless of what produced it.
