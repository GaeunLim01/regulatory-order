# AI Governance / Regulatory Order

A research repository for studying AI governance through **regulatory order**, using five parallel analytical layers to read selected cases.

## Current framework

Each case is read across the same five layers:

- **A — Classification:** object type and instability conditions
- **B — Formation:** event type and formation trace
- **C — Manifestation:** recorded manifestations such as boundary drift, classification decision, or documentation systems
- **D — Distribution:** source, bearer, bearer type, leverage, and distribution mechanisms
- **E — Re-formation:** re-formation responses and contextual amplification

These layers are **parallel analytical layers, not a sequence or causal chain**. A value in one layer does not determine, suppress, or overwrite a value in another.

The repository is deliberately selective. The cases are worked research material, not a complete corpus, and the working vocabulary remains open to revision when cases produce a deviation.

## Repository role

The site presents three things together: the AI-governance problem space, the current regulatory-order framework, and selected cases read through that framework. The framework is a current apparatus for continuing the inquiry, not a final claim about all regulatory orders.
